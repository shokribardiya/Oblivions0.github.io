ABOUT OBLIVION

We build systems for complexity.

Oblivion is an independent team of programmers, developers, researchers, and technology enthusiasts working across software engineering, artificial intelligence, data systems, and security research.

Modern information rarely exists in isolation.

Relationships reveal patterns. Oblivion develops software systems designed to make those relationships understandable — built from first principles, tested as working systems, and engineered to keep computation under the user's control whenever practical.

CYBERSECURITY

Security is an architectural property

Security belongs in the architecture of a system, not bolted on afterward. Oblivion's security work is research-oriented and defensive by design.

Defensive security engineering

Designing systems that are secure by default, not secured as an afterthought.

Security architecture & hardening

Structuring systems and infrastructure to reduce exposure and limit the impact of failure.

Vulnerability research & controlled testing

Responsible security research and threat analysis carried out in controlled environments.

Security research is conducted in controlled environments and on systems where appropriate authorization exists.

HOW WE THINK

An engineering philosophy, not a pitch

Six principles that shape how Oblivion approaches software, systems, and research.
01

Build from first principles.

Understand the system before abstracting it.

02

Make complexity visible.

Interfaces should reveal relationships instead of hiding them.

03

Connect information.

The value of data increases when relationships become understandable.

Security belongs in architecture, not as an afterthought.
